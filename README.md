# Zultys

## Z 23W IP Phone product page

Static, dependency-free build of the redesigned product page.

- Page: `phone/z-23w-ip-phone/index.html`
- Styles, script, images: `assets/z23w/`
- Generator and asset pipeline: `tools/`
- WordPress hand-off notes: `docs/z23w-wordpress-integration.md`

Preview locally with `python3 -m http.server` from the repo root, then open `/phone/z-23w-ip-phone/`.
